FIFA FBref Analysis

A practice project for a Python Data Analysis course.

This project analyzes FIFA player data merged with FBref statistics, exploring player performance, wages, market value, leagues, and age.

Data Processing

- Data cleaning and preprocessing
- Data type and memory optimization

Analysis

- FIFA Rating vs. Goal Contributions: Correlation = 0.22
- Weekly Wage vs. Market Value: Strong positive relationship
- Average FIFA Rating by League: Premier League has the highest average rating (78.3)
- Player Performance by Age: Performance is highest at age 17 and gradually declines with age
